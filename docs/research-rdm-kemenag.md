## 1. Regulasi Kurikulum Madrasah

### KMA 347 Tahun 2022 — Pedoman Implementasi Kurikulum Merdeka pada Madrasah
- **Tanggal penetapan:** 5 April 2022
- **Isi utama:** Memberikan pilihan kepada madrasah: menerapkan Kurikulum 2013 ATAU Kurikulum Merdeka
- **Ruang lingkup:** 10 bab — Standar Kelulusan, Standar Isi, Struktur Kurikulum, Implementasi, Pembelajaran dan Asesmen, P5 (Profil Pelajar Pancasila), KOM (Kurikulum Operasional Madrasah), Monev, Sosialisasi, Capaian Pembelajaran
- **Penerapan:** Bertahap mulai TP 2022/2023, dimulai dari madrasah percontohan/piloting
- **Ketentuan PAI & Bahasa Arab:** Standar Isi dan Capaian Pembelajaran mengacu pada ketentuan Kemenag (bukan Kemendikbudristek)
- **Ketentuan mapel umum:** Standar Isi dan CP mengikuti Kemendikbudristek
- **Struktur kurikulum:** Terbagi 2 — pembelajaran intrakurikuler + pembelajaran berbasis proyek (P5RA)
- **Struktur MA:** Fase E (Kelas X) dan Fase F (Kelas XI-XII)
- **Sumber:** https://docs.paralegal.id/PERMEN/PERMENAG/KEPMENAG/2022/KEPMENAG-347-2022.pdf

### KMA 450 Tahun 2024 — Pedoman Implementasi Kurikulum pada Madrasah (Revisi)
- **Status:** Menggantikan/memperbarui KMA 347/2022 dengan struktur yang lebih detail
- **Perubahan kunci vs KMA 347:**
  - Tabel alokasi JP lebih rinci per kelas (X, XI, XII terpisah)
  - Penambahan detail mata pelajaran pilihan
  - Pengaturan P5RA (Profil Pelajar Pancasila dan Rahmatan lil 'Alamin) lebih jelas
  - Penguatan program khusus madrasah

### Ketentuan Penting
- Peserta didik boleh mengganti mapel pilihan **paling lambat kelas XI semester 2**
- Madrasah program khusus: alokasi penguatan program Kelas X & XI minimal 72 JP, maksimal 216 JP/tahun; Kelas XII minimal 64, maksimal 192 JP/tahun
- Madrasah boleh menambah/merelokasi JP sesuai analisis CP, **maksimal 6 JP tambahan**
- **P5RA** = Projek Penguatan Profil Pelajar Pancasila dan Rahmatan lil 'Alamin — 2-3 projek per tahun dengan tema berbeda
- Muatan lokal bisa: (a) terintegrasi mapel lain, (b) terintegrasi tema P5RA, atau (c) mapel berdiri sendiri

## 3. Komponen Penilaian/Asesmen

### Berdasarkan PPA Kemenag (Panduan Pembelajaran dan Asesmen Madrasah, 2022)

#### 3.1 Asesmen Formatif
- **Tujuan:** Umpan balik untuk memperbaiki proses belajar (diagnostic)
- **Waktu:** Awal pembelajaran dan selama proses pembelajaran
- **Risiko:** Rendah (low-stakes)
- **Masuk nilai rapor?** ❌ **TIDAK** (pada PPA 2025 edisi revisi, formatif tidak masuk rapor)
- **Contoh:** Pertanyaan pemantik, refleksi, jurnal, penilaian antarteman, penilaian diri, observasi kinerja, kuis pemahaman

> **CATATAN PENTING:** Ada dua alternatif kebijakan:
> - **PPA Kemenag 2022 (versi awal):** Formatif BISA dimasukkan ke nilai rapor (Alternatif 1)
> - **PPA 2025 (edisi revisi Kemendikdasmen):** Formatif TIDAK masuk nilai rapor. Nilai rapor hanya dari sumatif.
> - **RDM secara praktek** hanya menyediakan input untuk **Sumatif** dan **SAS** (Sumatif Akhir Semester), sehingga de facto mengikuti model formatif tidak masuk rapor.

#### 3.2 Asesmen Sumatif
Terbagi dua jenis:

**a. Sumatif Lingkup Materi (SLM) / Sumatif Harian**
- Dilakukan setelah menyelesaikan satu atau lebih tujuan pembelajaran (TP) / lingkup materi
- Biasa disebut "ulangan harian" atau "penilaian harian (PH)"
- Bisa berupa: tes tertulis, observasi, praktik, produk, projek, portofolio
- Jumlah: beberapa kali per semester (sesuai jumlah TP/LM)
- Di RDM: diinput pada menu **"Sumatif"**, setiap entri diberi nomor urut TP/LM

**b. Sumatif Akhir Semester (SAS)**
- Dilakukan di akhir semester
- Bersifat **PILIHAN** (tidak wajib jika data sumatif sudah cukup — menurut PPA 2025)
- Biasa disebut "PAS" (Penilaian Akhir Semester) atau "PAT" (Penilaian Akhir Tahun)
- Bentuk: biasanya tes tertulis (pilihan ganda + uraian)
- Di RDM: diinput pada menu **"SAS"**

### Alur Penilaian di RDM
```
Guru Input Sumatif (per TP/LM) → Guru Input SAS → 
Sistem hitung Nilai Akhir otomatis → Deskripsi Capaian auto-generate → 
Wali Kelas verifikasi → Cetak Rapor
```

## 4. Formula Perhitungan Nilai Rapor

### 4.1 Formula di RDM (Praktek Aktual)

RDM menggunakan formula **pembobotan** antara rata-rata Sumatif dan SAS:

```
Nilai Akhir = (Rata-rata Sumatif × Bobot_Sumatif + Nilai SAS × Bobot_SAS) / (Bobot_Sumatif + Bobot_SAS)
```

**Di RDM, guru mengatur bobot melalui menu "Bobot":**
- **Bobot Sumatif** (nilai harian/SLM): diisi angka, misal 75
- **Bobot SAS** (nilai ujian semester): diisi angka, misal 25

**Contoh umum yang banyak dipakai madrasah:**
- Bobot Sumatif : SAS = **75 : 25** (paling umum)
- Bobot Sumatif : SAS = **60 : 40**
- Bobot Sumatif : SAS = **50 : 50**

> **Sumber langsung:** "Isi bobot SUMATIF/NILAI HARIAN : 75 dan SAS / NILAI UJIAN SEMESTER: 25"
> — Panduan Pengisian RDM (https://id.scribd.com/document/1063652439)

> **Sumber konfirmasi:** "Pengaturan Bobot Penilaian antara SUMATIF dan SAS bisa diatur sesuai keinginan guru mapel."
> — Panduan Pengisian Nilai RDM (https://id.scribd.com/document/965883624)

> **Sumber lapangan:** "Di kelas IV MIN 3 Malang bobot sumatif dan nilai hasil asesmen sumatif akhir semester atau PAS ini yaitu masing-masing 50%."
> — Skripsi UIN Malang (http://etheses.uin-malang.ac.id/66860/1/200103110125.pdf)

### 4.2 Perhitungan Detail

**Langkah 1: Hitung Rata-rata Sumatif (Nilai Akhir Sumatif)**
```
NA_Sumatif = (Sumatif_1 + Sumatif_2 + ... + Sumatif_n) / n
```
Dimana n = jumlah tujuan pembelajaran/lingkup materi yang diujikan

**Langkah 2: Hitung Nilai Rapor**
```
Nilai_Rapor = (NA_Sumatif × Bobot_Sumatif + Nilai_SAS × Bobot_SAS) / (Bobot_Sumatif + Bobot_SAS)
```

**Contoh Perhitungan:**
```
Sumatif 1 = 85, Sumatif 2 = 83, Sumatif 3 = 60, Sumatif 4 = 84
NA_Sumatif = (85+83+60+84)/4 = 78

Nilai SAS = 75
Bobot Sumatif = 75, Bobot SAS = 25

Nilai Rapor = (78 × 75 + 75 × 25) / (75 + 25) = (5850 + 1875) / 100 = 77.25 → 77
```

### 4.3 Tiga Opsi Pengolahan Nilai (PPA 2025 — Kemendikdasmen)
Panduan nasional menyediakan 3 opsi. Madrasah mengikuti ini melalui PPA Kemenag:

| Opsi | Deskripsi | Cocok Untuk |
|------|-----------|-------------|
| **Pembobotan** | Tiap sumatif diberi bobot sesuai tingkat kesulitan, dijumlahkan | Materi progresif (prasyarat) |
| **Persentase** | Hitung % tujuan pembelajaran yang tercapai | Materi berkaitan langsung |
| **Rata-rata** | Rerata semua nilai sumatif | Materi lepas (tidak prasyarat) |

> **Di RDM:** Sistem menggunakan **opsi pembobotan** (antara rata-rata sumatif dan SAS) yang ditetapkan madrasah. Bobot per individu sumatif TIDAK dibedakan di dalam RDM — semua sumatif dirata-rata lalu dibobotkan terhadap SAS.

### 4.4 Alternatif Pengolahan (PPA Kemenag 2022)
Dokumen PPA Kemenag menyebut dua alternatif:

**Alternatif 1:** Mengolah seluruh data formatif DAN sumatif → nilai rapor
- Nilai rapor = dari formatif + sumatif lingkup materi + sumatif akhir semester
- Pembobotan ditetapkan satuan pendidikan

**Alternatif 2:** Hanya sumatif → nilai rapor (yang dipakai RDM)
- Nilai rapor = dari sumatif lingkup materi + sumatif akhir semester
- Pembobotan ditetapkan satuan pendidikan

### 4.5 Contoh Data dari Dokumen Resmi
Dari PPA Kemenag (contoh MTs Informatika):

| Peserta | Sumatif 1 | Sumatif 2 | Sumatif 3 | Sumatif 4 | NA Sumatif | SAS (Non-Tes) | SAS (Tes) | NA SAS | Nilai Rapor (Rerata S+AS) |
|---------|-----------|-----------|-----------|-----------|------------|---------------|-----------|--------|---------------------------|
| Al | 85 | 83 | 60 | 84 | 78 | — | 75 | 75 | **76,5** |
| FIA | 64 | 68 | 40 | 96 | 67 | — | 50 | 50 | **58,5** |
| Pasma | 87 | 79 | 80 | 78 | 81 | — | 75 | 75 | **78,0** |
| Hakim | 90 | 90 | 90 | 94 | 91 | — | 100 | 100 | **95,5** |

> Rumus contoh: `Nilai Rapor = (NA_Sumatif + NA_SAS) / 2` (pembobotan 50:50)
> — Sumber: PPA Kemenag (https://mdrsh.id/v3/media/40e7581986de941887d14ccf98a13b8c342.pdf) dan https://anyflip.com/meulv/vvss/basic/201-250

### 4.6 Kriteria Ketercapaian
- **Tidak ada KKM baku nasional** — ditetapkan per satuan pendidikan
- Contoh di panduan: 0-55 = belum tercapai, 56-100 = tercapai (hanya ilustrasi)
- Ketercapaian ditentukan **per tujuan pembelajaran**, bukan dari nilai akhir saja
- Di RDM: guru mengisi **"Nilai Batas Ketercapaian"** per sumatif yang sudah disepakati dengan kepala sekolah dan wakakurikulum

## 5. Aplikasi RDM: Fitur & Alur Kerja

### 5.1 Tentang RDM
- Aplikasi berbasis **web** (self-hosted di server/hosting madrasah)
- Dikembangkan oleh **Tim Teknis Kemenag RI, Direktorat KSKK Madrasah**
- Jenjang: RA, MI, MTs, MA/MAK
- Data disinkronkan dari **EMIS** (Education Management Information System)
- URL akses: `https://rdm.[domain-madrasah]` atau `https://rdmq.[domain-madrasah]`
- **Wajib** digunakan — menjadi persyaratan kelulusan dan penerbitan ijazah, terintegrasi dengan PDUM dan Sistem Manajemen Ijazah

### 5.2 Peran/Akun di RDM

| Peran | Hak Akses Utama |
|-------|----------------|
| **Proktor** | Sinkron EMIS, kelola semua akun, upload logo, pengaturan cetak, backup/restore, atur TA & semester |
| **Staf/Admin** | Mirip proktor kecuali sinkron profil & backup |
| **Kepala Madrasah** | Monitoring, dashboard overview |
| **Guru Mapel** | Input nilai sumatif & SAS, atur bobot, kirim nilai |
| **Wali Kelas** | Verifikasi nilai, input catatan wali kelas, presensi, sikap spiritual/sosial, cetak rapor, legger |
| **Pembina Ekskul** | Input nilai dan deskripsi ekstrakurikuler |

### 5.3 Alur Kerja Pengisian Nilai

```
1. Proktor: Sinkron data dari EMIS (siswa, guru, mapel, kelas)
2. Proktor: Upload logo madrasah, atur TA/semester, setting cetak
3. Guru Mapel:
   a. Login → pilih mapel → pilih kelas
   b. Setting BOBOT (misal Sumatif:75, SAS:25)
   c. Input SUMATIF per TP/LM:
      - Nomor urut TP/LM (angka: 1, 2, 3, ...)
      - Deskripsi TP/LM (diawali KKO, tanpa huruf kapital di awal)
      - Nilai Batas Ketercapaian
      - Input nilai per siswa
   d. Input SAS (nilai ujian semester)
   e. Klik "Kirim Nilai"
4. Wali Kelas:
   a. Verifikasi status nilai 100%
   b. Cek nilai >= KKM, deskripsi berwarna hijau
   c. Input: catatan wali kelas, presensi, sikap
   d. Cetak rapor & legger
```

### 5.4 Menu Utama RDM (Guru Mapel)
- **Bobot** — Setting bobot Sumatif vs SAS
- **Penilaian > Sumatif** — Input nilai harian per TP/LM
- **Penilaian > SAS** — Input nilai ujian semester
- **Kirim Nilai** — Mengirim nilai ke wali kelas

### 5.5 Menu Utama RDM (Wali Kelas)
- **Rapor Siswa** — Sampul, Identitas, Nilai, Rapor, Rekap, Legger
- **Status Nilai** — Monitoring status pengisian per guru
- **Catatan Wali Kelas** — Input catatan naratif
- **Presensi** — Input kehadiran
- **Sikap** — Input sikap spiritual dan sosial

### 6.4 Fitur Cetak
- **Watermark** otomatis jika diisi (untuk kertas HVS putih polos)
- **Barcode** otomatis pada rapor cetak
- **Logo Kemenag** muncul otomatis (ukuran logo < 100KB, PHP ≤ 7.2 disarankan)
- Format: PDF, bisa cetak per siswa atau per kelas
- Legger tersedia dalam PDF dan Excel
- Rapor Kurikulum Merdeka menampilkan **Fase** di kop rapor

### 6.5 Deskripsi Capaian Kompetensi
- **Auto-generated** dari kata kunci yang diisi guru pada deskripsi TP/LM
- Diambil dari "poin penting materi" yang diisi guru
- Format: "[Nama siswa] [predikat] dalam [deskripsi TP/LM]"

## Ringkasan Teknis untuk Implementasi SIMMA

### Data Model Penilaian (per siswa per mapel per semester)
```
- bobot_sumatif: integer (misal 75)
- bobot_sas: integer (misal 25)
- sumatif[]: array of {
    nomor_tp: integer,
    deskripsi_tp: string,
    nilai_batas_tercapai: integer,
    nilai: integer
  }
- sas: {
    nilai_non_tes: integer (optional),
    nilai_tes: integer,
    nilai_akhir: integer
  }
- na_sumatif: computed = avg(sumatif[].nilai)
- nilai_rapor: computed = (na_sumatif * bobot_sumatif + sas.nilai_akhir * bobot_sas) / (bobot_sumatif + bobot_sas)
- deskripsi_capaian: auto-generated from sumatif[].deskripsi_tp
- predikat: derived from nilai_rapor vs batas_tercapai
```

### Halaman Rapor PDF yang Perlu Di-generate
1. Sampul (cover)
2. Identitas Peserta Didik
3. Lembar Nilai (sikap + nilai mapel + deskripsi capaian + ekskul + prestasi + catatan)
4. Rapor P5RA (terpisah)
5. Legger (rekap nilai per kelas)
6. Rekap Nilai (seluruh semester)
