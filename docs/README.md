# Dokumentasi Sistem SIMMA

Dokumen spesifikasi untuk Sistem Informasi Madrasah Aliyah (SIMMA):
- `RESEARCH.md`: Riset regulasi Kemenag (KMA 347/2022, KMA 450/2024, EMIS 4.0, RDM, P5RA).
- `PRD.md`: Spesifikasi kebutuhan fungsional & RBAC.
- `ARCHITECTURE.md`: Arsitektur decoupled (`simma-be` & `simma-fe`), skema PostgreSQL, dan API contract.
