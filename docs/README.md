# Dokumentasi Sistem SIMMA

Dokumen spesifikasi untuk Sistem Informasi Madrasah Aliyah (SIMMA):
- `PRD.md`: Spesifikasi kebutuhan fungsional makro & RBAC.
- `ARCHITECTURE.md`: Arsitektur decoupled (`simma-be` & `simma-fe`), skema PostgreSQL, dan API contract.
- `UX-DESIGN.md`: Panduan desain antarmuka, tata letak, dan tema sistem.
- `modules/`: Spesifikasi kebutuhan produk (PRD) modular untuk 19 modul madrasah.
